Security Policy

Supported Versions

Security updates are provided for the latest version of BakuBot.

Version	Supported
Latest	Yes
Older versions	No

Reporting a Vulnerability

If you discover a security vulnerability in BakuBot, please do not report it through a public GitHub Issue.

Instead, please report it privately through GitHub’s private vulnerability reporting feature, if available.

When reporting a vulnerability, please include:

* A clear description of the vulnerability.
* Steps to reproduce the issue.
* The potential security impact.
* Any relevant logs, screenshots, or code references.
* A possible fix, if you have one.

Please do not include passwords, API keys, OAuth tokens, Discord tokens, Twitch tokens, StreamElements tokens, or other sensitive credentials in your report.

Security Considerations

BakuBot may interact with third-party services such as Discord, Twitch, StreamElements, and Steam.

Users are responsible for keeping their API keys, OAuth tokens, bot tokens, environment variables, and other credentials secure.

Never commit secrets or credentials to the repository.

If a credential is accidentally exposed, revoke or rotate it immediately through the relevant service.

Responsible Disclosure

Please allow reasonable time for the vulnerability to be investigated and addressed before publicly disclosing the issue.

We appreciate responsible security research and reports that help make BakuBot safer for everyone.
